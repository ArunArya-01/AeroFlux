PHYSICS-GUIDED MACHINE LEARNING FOR AIRCRAFT FUEL CONSUMPTION PREDICTION

Predict aircraft fuel consumption from sparse flight data by combining aircraft-performance physics, dynamic mass representation, and machine learning.

Research Pipeline

01

Flight Data

Fused ADS-B and ACARS telemetry from EUROCONTROL PRC 2025 challenge. Sparse, noisy, incomplete.

↓
02

Physics Baseline

OpenAP first-principles fuel-flow estimate from aircraft type, speed, altitude, vertical rate, and reference mass.

↓
03

Dynamic Mass

Key R3 contribution: estimate aircraft mass in-flight from fuel-burn dynamics. Mass is rarely known but central to prediction.

↓
04

R3 Ensemble

Stacked gradient-boosted models (XGBoost, LightGBM, CatBoost) learn the residual between physics and reality.

↓
05

Distilled Model

Frozen teacher trains a compact MLP student. Runs in-browser via ONNX Runtime Web.

↓
06

Fuel Prediction

Per-interval fuel burn prediction validated against ground-truth labels.

Research & method

Fuel-burn prediction, explained

This demo visualizes a PRC-style flight replay. It combines a physics baseline with a learned residual model to estimate interval fuel burn and evolving aircraft mass.

Flight inputs

Altitude, groundspeed, vertical rate, route progress, and aircraft type are used as simulation inputs.

Prediction

OpenAP-style performance physics supplies a baseline; the R3 model corrects the remaining error.

What to compare

Use the live panels and chart to compare predicted fuel burn with the supplied ground-truth intervals.

The headline RMSE values are test-set aggregate benchmarks, not accuracy guarantees for this single replay. The displayed flight values are provided by the current demo data source.
